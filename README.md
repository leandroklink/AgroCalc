# AgroControl ERP

AgroControl é um sistema web desenvolvido como projeto acadêmico para auxiliar na gestão de atividades agrícolas.

Inicialmente, o projeto tinha como objetivo atender aos requisitos da disciplina, mas foi expandido para incluir funcionalidades adicionais como autenticação de usuários, dashboard interativo, histórico de atividades e deploy em ambiente web.

## Funcionalidades

* Cadastro e gerenciamento de talhões
* Controle de custos operacionais
* Simulação de financiamentos
* Cálculo de fertilizantes
* Conversões agrícolas
* Dashboard com indicadores e gráfico de produção
* Histórico de atividades
* Cadastro e login de usuários
* Modo escuro
* Interface responsiva para dispositivos móveis

## Tecnologias Utilizadas

* Python
* Flask
* SQLite
* HTML
* CSS
* JavaScript
* Chart.js

## Objetivo

Além de atender aos requisitos acadêmicos, este projeto foi utilizado como forma de aprofundar conhecimentos em desenvolvimento web, banco de dados, autenticação de usuários, responsividade e deploy de aplicações.
